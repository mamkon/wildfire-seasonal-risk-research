# Canada Wildfire Power BI report

Open `Canada Wildfire.pbip` in Power BI Desktop. When using the ZIP, extract it first and keep the Report and SemanticModel folders beside the project file. If prompted on first open, select **Refresh now** to load the embedded tables.

This review build has nine pages and eight embedded summary tables from the 2000–2025 CNFDB analysis of 12 reporting agencies. The page tabs provide navigation. The Map page ranks the 20 rounded coordinate cells with the most recorded area. Record-level slicers, geographic map rendering and drill-through are outside this summary build. Headlines are marked for review.

The Trust page records the comparison with the 2025 annual report. The full 2023 source-year count and rounded area match its published national table. The narrower chart scope still carries the pending NFD reconciliation label. See the [official annual report](https://prod-natural-resources.azure.cloud.nrcan-rncan.gc.ca/forests-forestry/state-canada-forests/state-canada-s-forests-annual-report-2025).
